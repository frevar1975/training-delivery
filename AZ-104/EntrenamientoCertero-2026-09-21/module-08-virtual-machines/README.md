# Módulo 8 — Administración de máquinas virtuales

## Demo de esta ejecución

[Escalado provocado de una web con VMSS](demos/demo-01-vmss-autoscale-web/README.md).

Los alumnos envían cálculos desde una página web. El instructor puede reforzar el tráfico con PowerShell. Azure Monitor aumenta de una a dos instancias por CPU promedio y reduce al terminar la carga.

En clase se relaciona la observación con escalado horizontal, VM Scale Sets, sondas y balanceo. Los temas de planificación de VMs, discos, acceso y opciones de disponibilidad se explican con el PowerPoint oficial.
