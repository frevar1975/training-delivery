# Prompts para Demo AI-900 - Azure MCP Governance

## Objetivo

Demostrar cómo un agente de IA puede interactuar con recursos reales de Azure mediante herramientas, contexto y permisos controlados.

---

## Prompts sugeridos para Copilot CLI

### 1. Listar recursos

```text
Lista los recursos del resource group rg-demo-ai900-mcp.
```

### 2. Revisar gobierno

```text
Identifica qué recursos no tienen tags.
```

### 3. Explicar el problema

```text
Explícame por qué un recurso sin tags puede ser un problema de gobierno en Azure.
```

### 4. Proponer corrección

```text
Sugiere una política simple de etiquetado para estos recursos.
```

### 5. Resumen ejecutivo

```text
Dame un resumen ejecutivo de esta revisión para un gerente no técnico.
```

### 6. Relación con AI-900

```text
Explica cómo esta demo se relaciona con conceptos de IA generativa, agentes y responsabilidad en IA.
```
