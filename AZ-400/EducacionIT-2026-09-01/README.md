# AZ-400 - Designing and Implementing Microsoft DevOps Solutions

Material reutilizable para la preparación y dictado del curso AZ-400.

## Estructura del curso

### Module 00 - Welcome

Preparación y validación del entorno.

Lab:
- Lab 00 - Validate Lab Environment

### Module 01 - Implement Development for Enterprise DevOps

Planificación Agile y control de versiones.

Labs:
- Lab 01 - Agile Planning and Portfolio Management with Azure Boards
- Lab 02 - Version Control with Git in Azure Repos

### Module 02 - Implement CI with Azure Pipelines and GitHub Actions

Continuous Integration, agentes, pipelines, GitHub Actions y containers.

Labs:
- Lab 03 - Configure Agent Pools and Understand Pipeline Styles
- Lab 04 - Enable Continuous Integration with Azure Pipelines
- Lab 05 - Implement GitHub Actions for CI/CD
- Lab 06 - Deploy Docker Containers to Azure App Service

### Module 03 - Design and Implement a Release Strategy

Pipelines YAML, release gates y pruebas funcionales.

Labs:
- Lab 07 - Configure Pipelines as Code with YAML
- Lab 08 - Control Deployments using Release Gates
- Lab 09 - Set Up and Run Functional Tests

### Module 04 - Implement Secure Continuous Deployment

Secretos, Azure Key Vault y configuración dinámica.

Labs:
- Lab 10 - Integrate Azure Key Vault with Azure DevOps
- Lab 11 - Enable Dynamic Configuration and Feature Flags

### Module 05 - Manage Infrastructure as Code

Infraestructura como código utilizando Azure Bicep.

Lab:
- Lab 12 - Deployments using Azure Bicep Templates

### Module 07 - Design and Implement a Dependency Management Strategy

Administración de paquetes y dependencias.

Lab:
- Lab 13 - Package Management with Azure Artifacts

### Module 08 - Implement Continuous Feedback

Performance testing, observabilidad y conocimiento compartido.

Labs:
- Lab 14 - Monitor Application Performance with Azure Load Testing
- Lab 15 - Share Team Knowledge using Azure Project Wiki

## Directorios adicionales

- demos: demostraciones reutilizables
- labs: guías y preparación de laboratorios
- prompts: prompts utilizados durante el curso
- scripts: scripts utilizados en demos y labs
- datasets: archivos de datos para prácticas
