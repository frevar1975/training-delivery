# Module 00 - Welcome

## Objetivo

Preparar el entorno de trabajo necesario para realizar los laboratorios del curso AZ-400.

## Antes de comenzar

Durante el curso trabajaremos principalmente con:

- Azure DevOps
- Azure Repos
- Azure Boards
- Azure Pipelines
- GitHub
- Azure Portal
- Git
- Visual Studio Code
- Azure CLI

## Azure DevOps

Azure DevOps proporciona servicios para soportar diferentes etapas del ciclo DevOps.

Servicios principales:

- Azure Boards
- Azure Repos
- Azure Pipelines
- Azure Test Plans
- Azure Artifacts

## Azure Boards

Permite administrar:

- Epics
- Features
- User Stories
- Tasks
- Bugs
- Backlogs
- Sprints

## Azure Repos

Permite administrar repositorios Git y control de versiones.

## Azure Pipelines

Permite implementar procesos de:

- Continuous Integration
- Continuous Delivery
- Build
- Test
- Deployment

## Azure Artifacts

Permite administrar paquetes y dependencias.

## GitHub

Durante el curso también se utilizará GitHub para escenarios relacionados con:

- repositories
- pull requests
- GitHub Actions
- CI/CD

## Preparación del entorno

Antes de iniciar los laboratorios verificar:

1. Acceso a Azure Portal
2. Acceso a Azure DevOps
3. Organización de Azure DevOps disponible
4. Proyecto disponible
5. Git instalado
6. Visual Studio Code disponible
7. Acceso a GitHub cuando corresponda

## Comprobaciones rápidas

Git:

git --version

Azure CLI:

az version

## Mensaje clave

Antes de automatizar un proceso DevOps debemos asegurarnos de que:

- las herramientas estén disponibles
- las identidades tengan acceso
- los repositorios sean accesibles
- el entorno del laboratorio esté preparado
