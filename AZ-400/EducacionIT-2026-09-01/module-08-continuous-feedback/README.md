# Module 08 - Implement Continuous Feedback

## Objetivo

Comprender cómo incorporar mecanismos de feedback continuo dentro del ciclo DevOps para mejorar calidad, rendimiento y colaboración.

## Conceptos clave

- Continuous Feedback
- Monitoring
- Application Performance
- Load Testing
- Observability
- Team Knowledge
- Project Wiki
- Feedback Loops

## Explicación sencilla

DevOps no termina cuando una aplicación se despliega.

Después del deployment necesitamos observar:

- rendimiento
- errores
- comportamiento
- experiencia del usuario
- conocimiento generado por el equipo

## Ciclo de feedback

Plan
? Develop
? Build
? Test
? Deploy
? Monitor
? Learn
? Improve

## Continuous Feedback

El feedback continuo permite utilizar información real para mejorar:

- código
- arquitectura
- pipelines
- procesos
- documentación

## Monitoring

El monitoreo permite detectar:

- errores
- degradación de rendimiento
- tiempos de respuesta altos
- fallos de servicios
- problemas de capacidad

## Load Testing

Las pruebas de carga permiten analizar cómo responde una aplicación cuando aumenta la cantidad de usuarios o solicitudes.

Ejemplo:

100 users
? Application
? Measure response
? Analyze performance

## Métricas comunes

- response time
- throughput
- failed requests
- latency
- resource utilization

## Azure Load Testing

Azure Load Testing permite ejecutar pruebas de carga administradas desde Azure.

Puede integrarse con pipelines para validar rendimiento antes de liberar una aplicación.

## Team Knowledge

El conocimiento del equipo también forma parte de DevOps.

Debe documentarse:

- arquitectura
- procedimientos
- decisiones
- troubleshooting
- estándares
- prácticas operativas

## Azure Project Wiki

Azure DevOps permite crear una Wiki dentro del proyecto.

Puede utilizarse para compartir:

- documentación técnica
- procedimientos
- diagramas
- instrucciones
- conocimiento operativo

## Feedback técnico

Application

? Analysis

## Feedback de equipo

Experience
? Documentation
? Shared Knowledge
? Better Decisions

## Mensaje clave

DevOps necesita ciclos rápidos de feedback.

El objetivo no es solamente entregar software.

También debemos:

- medir
- aprender
- documentar
- mejorar continuamente
