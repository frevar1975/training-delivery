
# Module 02: Implement CI with Azure Pipelines and GitHub Actions

## Objetivo

Comprender cómo implementar Continuous Integration utilizando Azure Pipelines y GitHub Actions.

## Conceptos clave

- Continuous Integration
- Repositories
- Triggers
- Pipelines
- Agent Pools
- Agents
- Jobs
- Tasks
- Artifacts
- YAML
- GitHub Actions

## Explicación sencilla

Continuous Integration permite validar automáticamente los cambios de código.

Flujo:

```text
Developer
   |
   v
Commit / Push
   |
   v
Repository
   |
   v
Trigger
   |
   v
Pipeline
   |
   v
Agent
   |
   v
Build / Test
   |
   v
Artifact
```
