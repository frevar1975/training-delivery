# AI-901 — Netxpress

Delivery del curso **AI-901T00-A: Introducción a la IA en Azure** para Netxpress.

1. Fundamentos de IA, cargas de trabajo, IA responsable y primera demo generativa.
2. Microsoft Foundry, modelos, prompts, aplicaciones generativas y agentes.
3. Texto, voz, visión, extracción de información e integración.
