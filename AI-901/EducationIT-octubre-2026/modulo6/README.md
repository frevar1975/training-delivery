# Módulo 6 — Extracción de información

Demos para acompañar la presentación AI-901T00-PowerPoint_06.

## Secuencia sugerida

1. **Documentos individuales y por lote:** [DocuLens — Content Understanding](demo-content-understanding-lotes/README.md). Descargar los PDF ficticios desde el portal; probar Read, Layout y Receipt.
2. **Audio:** [Transcripción con Azure Speech](demo-speech-audio-upload/README.md). Generar un audio de prueba y mostrar voz → transcripción.
3. **Agente:** [De una llamada a un caso de atención — Foundry + Python](demo-agente-atencion-foundry/README.md). Crear un Prompt Agent en el portal y ejecutar la versión en código, donde el agente llama una herramienta Python para consultar citas o pedidos ficticios.

La comparación de Read con Layout/Receipt se realiza dentro de DocuLens. Usa únicamente los ejemplos ficticios. El demo del agente requiere un deployment de modelo en el proyecto Foundry; subir audio también requiere el recurso Azure Speech y FFmpeg.
