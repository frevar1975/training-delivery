# Checklist del instructor

## Antes de la clase

- [ ] Revisar objetivos y agenda.
- [ ] Confirmar enlace de EducaciónIT.
- [ ] Tener abierta la presentación.
- [ ] Verificar conexión, audio y pantalla.
- [ ] Preparar ejemplos de IA.
- [ ] Confirmar material de Microsoft Learn.

## Durante la clase

- [ ] Registrar asistencia.
- [ ] Explicar objetivos.
- [ ] Verificar comprensión con preguntas.
- [ ] Permitir participación.
- [ ] Registrar dudas para la siguiente sesión.

## Después de la clase

- [ ] Registrar temas cubiertos.
- [ ] Anotar preguntas pendientes.
- [ ] Actualizar estado de la sesión.
- [ ] Preparar conexión con Machine Learning.
